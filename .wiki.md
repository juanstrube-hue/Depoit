# Project Summary
The project is a modern fintech web application designed for contract management, deposit returns, and notifications tailored for landlords, tenants, and brokers. It aims to streamline financial transactions and enhance user experience by providing a secure, efficient platform for managing financial agreements and deposits.

# Project Module Description
- **Backend**: Manages data storage, authentication, and business logic through a structured API.
- **Frontend**: Offers a responsive user interface built with React, featuring navigation, authentication, and content display components.
- **Database**: Utilizes PostgreSQL to store user profiles, contract details, and transaction records.

# Directory Tree
```
app/
├── backend/                # Backend service files
│   ├── core/               # Core functionalities and configurations
│   ├── data_models/        # JSON data models for contracts and notifications
│   ├── dependencies/       # Dependency injection and database connections
│   ├── models/             # Data models for ORM
│   ├── routers/            # API route definitions
│   ├── services/           # Business logic and service layer
│   ├── schemas/            # Data validation schemas
│   ├── main.py             # Entry point for the backend application
│   └── requirements.txt     # Python dependencies
└── frontend/               # Frontend service files
    ├── src/                # Source code for the React application
    ├── public/             # Static assets
    ├── package.json        # Node.js dependencies
    └── vite.config.ts      # Vite configuration
```

# File Description Inventory
- **app/backend/main.py**: Main entry point for the backend application.
- **app/frontend/src/App.tsx**: Main component of the React application.
- **app/backend/requirements.txt**: Lists Python dependencies required for the backend.
- **app/frontend/package.json**: Lists Node.js dependencies required for the frontend.
- **app/frontend/src/pages/**: Contains various page components for the application, including Dashboard, Contracts, Wallet, Activity, and Settings.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Vite
- **Database**: PostgreSQL
- **Styling**: Tailwind CSS

# Usage
To install dependencies, build, and run the application:

1. **Backend**:
   - Navigate to the backend directory: `cd app/backend`
   - Install dependencies: `pip install -r requirements.txt`
   - Run the application: `python main.py`

2. **Frontend**:
   - Navigate to the frontend directory: `cd app/frontend`
   - Install dependencies: `npm install`
   - Build the application: `npm run build`
   - Start the application: `npm run dev`
