# Project Summary
Depoit is a Chilean fintech web application designed for rental deposit custody management. It enables landlords, tenants, and brokers to efficiently manage rental contracts, track deposits through a secure lifecycle, handle deposit returns with deductions, and receive notifications. The platform employs dual state machines to monitor the lifecycle of contracts and deposits, enhancing transparency and user experience.

# Project Module Description
- **Backend**: Built with FastAPI and SQLAlchemy, it handles data storage, authentication, and business logic through a structured API.
- **Frontend**: A responsive user interface developed with React, TypeScript, and Vite, facilitating navigation, authentication, and content display.
- **Database**: Utilizes PostgreSQL for storing user profiles, contract details, and transaction records.
- **Atoms Cloud**: Integrated for authentication and object storage.

# Usage
To install dependencies, build, and run the application:

1. **Backend**:
   - Navigate to the backend directory: `cd app/backend`
   - Install dependencies: `pip install -r requirements.txt`
   - Run the application: `python main.py`

2. **Frontend**:
   - Navigate to the frontend directory: `cd app/frontend`
   - Install dependencies: `npm install`
   - Build the application: `npm run build`
   - Start the application: `npm run dev`
