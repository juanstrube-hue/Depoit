# Project Summary
The project is a modern fintech web application that facilitates contract management, deposit returns, and notifications for landlords, tenants, and brokers. It aims to streamline financial transactions and enhance user experience by offering a secure and efficient platform for managing financial agreements and deposits. Recent updates include a refined contract lifecycle management system and a comprehensive Contract Creation wizard, which simplifies the contract setup process while improving usability and responsiveness.

# Project Module Description
- **Backend**: Handles data storage, authentication, and business logic via a structured API using FastAPI and SQLAlchemy.
- **Frontend**: Provides a responsive user interface built with React and TypeScript, featuring navigation, authentication, and content display components.
- **Database**: Employs PostgreSQL for storing user profiles, contract details, and transaction records.

# File Description Inventory
- **app/backend/main.py**: Main entry point for the backend application.
- **app/frontend/src/App.tsx**: Main component of the React application, managing routing and application state.
- **app/backend/requirements.txt**: Lists Python dependencies required for the backend.
- **app/frontend/package.json**: Lists Node.js dependencies required for the frontend.
- **app/frontend/src/pages/ContractNew.tsx**: Component for creating new contracts, now includes new state fields.
- **app/frontend/src/pages/ContractDetail.tsx**: Displays contract details and serves as the operational center for actions and timeline events.
- **app/frontend/src/pages/Dashboard.tsx**: Displays key metrics and contract summaries for users.
- **app/frontend/src/pages/Contracts.tsx**: Lists all contracts with filtering options based on status and search criteria.
- **app/frontend/src/lib/utils.ts**: Contains utility functions for formatting and state management.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Vite
- **Database**: PostgreSQL
- **Styling**: Tailwind CSS

# Usage
To install dependencies, build, and run the application:

1. **Backend**:
   - Navigate to the backend directory: `cd app/backend`
   - Install dependencies: `pip install -r requirements.txt`
   - Run the application: `python main.py`

2. **Frontend**:
   - Navigate to the frontend directory: `cd app/frontend`
   - Install dependencies: `npm install`
   - Build the application: `npm run build`
   - Start the application: `npm run dev`
